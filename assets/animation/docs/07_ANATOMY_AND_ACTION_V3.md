# V3：结构完整与动作逻辑验收

本轮用户认可现有色块、轮廓、配色和夸张程度，但明确否决怪异的肢体、缺块、突块，以及无法理解施力关系的画面。此规范优先于 V2 的美术通过记录；旧评分不能覆盖新发现的缺陷。

## 一、可以概括什么，必须保留什么

可以省略毛丝、肌肉细节和被合理遮挡的手指，可以夸大前臂、肩背和动作幅度。必须保留能解释姿态的身体关系：肩接上臂，上臂通过一个肘连接前臂，前臂通过腕连接掌，爪从手指末端生长。前后遮挡必须一致。画面只出现一只手时，不要求补画全身，但手腕与出画方向必须连贯。

夸张的对象是力量、体积、节奏和透视，不是新增关节、额外肢体或无法解释的骨骼连接。剪影同样要经得起这项检查。

## 二、具体失败类型

| 失败类型 | 本轮观察到的表现 | 修正要求 |
|---|---|---|
| 被遮挡区被挖掉 | 动画远侧手臂减去胸辫区域，旋转后露出缺口 | 补画完整手臂；胸辫独立前景遮挡，不从肢体中扣除 |
| 底图多画一块身体 | 去臂躯干补出圆鼓毛团，抬臂后像额外后背 | 底图只延续胸背体积与连续外缘；覆盖所有允许姿态检查 |
| 肩肘路线不清 | 防御时前臂绕头、绕胸形成闭环 | 两条手臂各有可追踪的肩、肘、腕；改变姿势而不是以特效遮住 |
| 掌形被物体取代 | 天崩地裂的前臂和掌变成一整块石板 | 保留连续前臂、腕、掌与指根；撞击和雷震由接触点及外部裂纹表达 |
| 手消失或变成炮口 | 对称圆筒前臂、没有可解释的掌端 | 明确掌面或指节；能量不能替代腕掌结构 |
| 爪从错误位置长出 | 掌侧、手腕冒出骨钩或镰钳 | 缩短到有结构依据的指端弯爪；外部骨甲与手掌分离 |
| 施术者与受体混为一体 | 熊头融在石块上，自己延伸成巨爪 | 明确施术肢体、接触处、外部对象和局部变化 |

## 三、卡面检查门槛

1. **肢体数量与连接**：可见肢体不多不少；每一段都能解释它从哪里来、接到哪里去。
2. **关节与手掌**：肘只有一次有依据的弯折，手腕无突兀反折，掌内没有凭空的孔、裂面或新增爪根。
3. **头口与躯干**：上下颌相接，牙在口腔内；胸、腹、肩背不互相穿过或长出多余质量块。
4. **遮挡与负形**：被挡住的部位可以合理接续；手臂之间、臂与躯干之间的空隙不构成错误断肢。
5. **受力与因果**：格挡能看出冲击来自哪里；攻击能看出由什么接触目标；侵染能看出谁施加给谁。
6. **小尺寸**：1000、250、125 像素及灰度预览仍成立；重要腕掌和接触点经一代卡型遮罩后仍能读到。
7. **系列一致性**：保留宽肩、粗前臂、低重心、白灰上身与深蓝身体、青色弯爪；保持硬边概括，不因修解剖改成写实海报。

任何一项出现明确结构矛盾即返修。不能用总分、配色漂亮、主体占比正确或尺寸检查通过抵消结构失败。正向参照为用户认可的 B01、U19、U37；不要继续把已被本轮否决的旧 B02、旧 U28、旧 R28 当作造型基准。

## 四、动画检查门槛

- 完整部件先成立，再装配：被其他层遮住的肌体也要补齐；遮挡由层次或局部遮罩控制。
- 统一坐标与比例：维持原参考肩宽、胸厚、头身比例、前臂和腿长；不用非均匀拉伸弥补错位。
- 每个动作检查全部导出帧，并单独检查关闭雷电、光晕和拖尾后的身体。动作极值、起落、切换和循环接头另行放大。
- 重点看肩、肘、腕、腋下、胸辫下缘、后背、髋与膝；既检查透明缺口，也检查重叠层导致的多余凸起。
- 轮廓连续不等于结构正确：正确毛簇与背峰可以突出；没有体积依据的硬角、圆包、重复肩部不能保留。
- 领域和普通形态使用同一套完整身体；弱血、跳跃、死亡不豁免结构检查。
- 技术扫描只能定位候选问题。透明区域有时是正常腋下负形，亮色内纹也不是孔洞；由真实视觉检查判定，不自动填平全部凹陷。

## 五、记录与复现

每项通过记录绑定实际图片 SHA256，并写下看的原图、预览或逐帧页面。新图由另一位审稿者复看。拒稿与返修原因保留为文字和必要的小对照图；交付包以当前成品和可复现源文件为主。

三个交付仓库独立打包：动画、卡片、必要参考。每个文件可以单独解压，不能再使用 `.001/.002/.003` 分卷。
