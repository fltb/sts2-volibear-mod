# V4：原图结构保全与爪面方向检查

本文件回应用户指出的两个实际回归：动画切块误删躯干及角色右腿上部；B02 防御的右侧爪子掌面与指甲朝向矛盾。V3 对这两个部位的“通过”结论已被用户反馈推翻，不能继续作为批准依据。

## 1. 先固定“哪个部位”

- 角色原始参考朝画面右侧。角色的右腿是画面左侧、离观察者较近的一条腿。
- 躯干、腰腹、骨盆、大腿根、大腿、小腿、踝和足是连续体积。手臂下方的暗毛不能因为颜色深或接近手臂而被当作透明背景。
- B02 本轮目标是画面右侧竖起护脸的那只爪。描述方向同时写出画面侧与朝向，不只写“右手”。

## 2. 本轮缺陷是怎样产生的

V3 的身体准备脚本使用整张补绘底画，再应用一条向内凹的裁剪多边形，以去掉抬臂后出现的多余肩背块。该边界延伸到了原图实际可见的腰腹和近侧髋部，把它们一并切成透明。轮廓仍然连通，身体也没有新分离碎片，因此只查连通性、图集或文件完整性无法发现这个错误。

B02 旧图在掌面向内的防御姿势上，画了一排朝外翻出的长爪。爪根、手指卷曲和掌背朝向没有共同遵守同一个三维方向。即使两条手臂各自连接完整，这个局部仍然是错的。

## 3. 切块前后的强制对照

1. 使用仓库内批准原图，不用上一版装配结果代替原图。
2. 在原图的统一坐标、统一尺度下显示原图、实际透明合成的分层还原、差异图。比较前不能分别缩放或拉伸各个部位。
3. 把 RGBA 图像先真实合成到不透明灰底，再另用棋盘底复查。RGB 通道里残留颜色不代表 alpha 仍然存在。
4. 每张活动图层都先单独在灰底上检查，确认隐藏肩部、完整手臂内部没有来自原图遮挡边界的低透明度线或拼接痕；不能把原图的外轮廓复制进本应实心的隐藏区域。再分开检查头、胸背、腰腹、髋、大腿、膝、小腿、足、两条手臂、两只爪和胸辫。任何可见区域被删薄或替换，都要解释其归属，不能用“整体看起来差不多”跳过。
5. 原图已经可见的躯干和双腿优先直接保留。仅在原先被活动手臂遮挡、动作后确实会露出的范围补底，不拿整张生成图覆盖所有身体像素。
6. 保护区检查比较 RGBA，不只比较外接框、面积或连通域。保护区不能事后缩小到恰好让错误通过。
7. 逐个检查闭嘴、半张嘴、张嘴身体层。嘴部替换窗口只覆盖嘴和真实下颚，不能把附近属于远侧手臂的肩纹或毛块带进静止身体层。张嘴和抬臂同时出现的帧必须另查；也不能简单删除所有手臂归属区而误切实际下颚。
8. 零姿态复原通过以后，再看动作中最大抬臂、交叉防御、深弯腰、重击、反击、跳跃、领域与低血姿势。原图的腿不能在动作里跟随手臂被搬走或露出切口。

## 4. 爪子朝向检查

每只爪都要能回答：前臂从哪里来，腕关节朝哪里弯，掌心朝哪个方向，掌背在哪一面，指根如何连到指节，指尖和指甲向哪里收拢。

对于 B02 本轮的向内护脸爪，外侧应读作连贯的掌背和弯曲指节；爪尖应随手指向内侧收拢，可被遮挡，只露出合理的一部分。不能为了展示全部蓝爪，把指甲重新翻到外侧。也不能只镜像爪尖而保留相反的指节结构。

检查先看大图，再看实际 250 像素卡面和裁切后的类型遮罩。缩略图能读懂动作不能取代大图的解剖方向检查。

## 5. 返修与证据

- 每一次修改共同身体层，全部使用该层的动作都失去旧版视觉批准，必须同步导出并检查。
- 对原图保护区的数值检查、技术文件检查、视觉判断分别记录。技术通过只证明其检查范围，不等于“所有画面没有错误”。
- 记录实际看过的文件、动作、帧区间和当时的 SHA256；未看过的图不能写成通过。
- 发现明确缺陷就继续返修；完成报告要写具体修复及检查范围，避免无依据的“百分之百无误”。
- 日后新增源图或改变保护区、分层、变形方式时，重新执行原图还原检查，不继承本轮结论。

本轮实际输出及具体检查记录分别位于动画仓库的 `reports/animation_revision_v4/` 和卡片仓库的 `reports/revision_v4/`。参考仓库只保存本规则及必要参考，不承担成品批准。
