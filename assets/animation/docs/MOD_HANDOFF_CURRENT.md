## 接入约束

1. 使用clean角色加独立VFX；不要再叠加旧baked角色图集，以免重复特效。
2. 保留清单的动作事件与状态规则。表现只消费已经提交的规则事件；不重随机目标、不重复结算、不自行修改卡表。
3. 音频/事件/角色状态映射以现有清单为准；未实现的游戏功能明确标注，不能用素材存在证明玩法已实现。
4. 不修改角色其他已接受外观。需要美术变更时反馈给用户，不另起自动审稿长循环。
5. 实际工程编译、资源加载与战斗播放分别验证；没有完成就不要宣称通过。
