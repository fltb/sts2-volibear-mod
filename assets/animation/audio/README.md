# 声音成品与接入

默认运行方案仍为下述开放音频。现在也可显式构建 [Riot 英文私有音频方案](profiles/README.md)：11 个 cue 使用经过来源及摘要验证的英文发声/Q 研发音效，其余 cue 保留开放素材，实际媒体只写入被忽略的本地构建目录。

V5.1 另附 [官方原始音频来源目录](official/index.html)：历史清单为 153 个 OGG，含 Wiki 默认英配和腾讯官方国服选择/禁用入口。公开 Git 不含这些 Riot 媒体；历史报告不代表 fresh clone 已下载文件。说明与来源见 [official/README.md](official/README.md)。

打开 `index.html` 可逐项播放。`ogg/` 是运行素材，`wav/` 为 48 kHz、16-bit、单声道母版。游戏可按实体位置进行声像处理；领域环境声不占用语音通道。

47 个独立声音对应 54 个逻辑 cue：40 个特效 cue、13 个角色发声 cue 和 1 个脚步 cue。部分机制复用同一基础声音，这是统一声音语言的明确映射，不是缺文件。

## 发声策略

角色没有强制台词配音要求。本包提供实际无台词声音，包括攻击 A/B、重击、咬击、施法、受击 A/B、低血、咆哮、兽化、倒下，以及选择和胜利。可关闭 Voice 通道。低血声音只在进入状态时触发，不能每次待机循环都发声。选择 A/B 时使用独立的表现计数器，不消耗游戏随机数。

`action_cues.json` 按现有 26 段动作的演出事件给出示范时间。实际游戏的伤害、格挡、雷伤、净化和兽化声音应由**成功结算事件**驱动；不能在播放声音或特效时反过来实施游戏规则。

## 结构与混音

- 每个 cue 都有 `file`、`wav`、`loop`、`duration_seconds`、`bus`、冷却时间和并发上限，路径相对于 `audio/`。
- 使用 Voice、Sfx、Ambience 三条独立通道；建议分别 -3、-3、-6 dB，保留 6 dB 总线余量。
- `domain_loop` 与 `feral_aura` 是周期频谱生成的 4 秒循环。每次状态开始只创建一个播放实例；状态结束、死亡和离开房间时渐退并释放。
- `feral_aura` 默认关闭：当前卡表的兽化首先是卡牌转换，不能让声音误导为一个永久角色变身状态。
- 高频事件限制并发和冷却；全体雷伤完成一次结算只播放一次主声，不能随每个目标叠成爆音。
- 中断动作时取消尚未触发的演出 cue；不要取消已经成功结算的命中反馈。

## 可复现与验证范围

```bash
python3 audio/scripts/build_audio.py
python3 audio/scripts/validate_audio.py
```

已下载原始素材随包保留，重建不需要联网。需要重新下载时才运行 `fetch_cc0_sources.py`。声音由真正的 CC0 录音剪辑和可复现合成构成，不是音频文件的空壳。

验证覆盖全部文件解码、采样率、时长、非静音、文件哈希、峰值、循环接点和 cue/动作引用。短于 400 ms 的文件不报告虚假的综合响度，清单保留 `integrated_lufs: null` 并改用峰值和 RMS。离线浏览器与 Godot 的播放/解码验证属于技术验证；没有记录真人听审或游戏内混音验收。
