# V5 · 战斗、卡牌与机制特效

打开 `index.html` 可离线播放实际图集。这里交付 **40 种独立透明特效、1070 张运行帧、16 种机制图标、89 张卡的逐项事件映射**。短特效按 24 fps 输出；每种都有 PNG 帧、PNG/JSON 图集、GIF 预览、透明 WebP 预览和可编辑生成源。

这些素材延续工程原有的原生代码特效方式：用确定性的多边形、粗细变化的弧形划痕、少量折雷和大块剪影构成。没有下载或重打包《英雄联盟》或《杀戮尖塔》的特效贴图。角色原画与卡图在示例中只作已有项目素材的上下文参照，不被特效生成器重画。

## 设计语言

实体接触以短促、有方向的宽形为主，暖赭表示力量和碰撞。雷电以一条主要折线带少量支路，青色外缘与浅色细芯分层；群雷在实际受体上分配，不靠大量分叉暗示伤害次数。防护保留中间的空隙，避免挡住角色爪和肩部。领域的主要面积放在脚下与身后，持续循环低亮度。卡牌效果围绕实际卡面四角、费用点和局部表面，跟角色的身体变形保持清楚的语义界线。

兽化是**牌的形态改变**。`feral_transfer` 先由施术者传递至外部选中卡牌，再在插画右侧的落点附近局部扩散；`feral_claw` / `feral_body` 分别表示爪形与躯形。角色上只可有短暂的地面兽性提示，不能把本来未改变的身体、头发或肢体画成侵染目标。`examples/feral_transfer_storyboard.png` 与同目录 GIF 展示完整动作逻辑。

## 接入约定

- PNG 为 **straight alpha**；默认普通 alpha 混合，不需要加色混合。画布 256×256，图集每行 8 格。PNG 和图集是运行规范，GIF 只是预览。
- `pivot_px`、`anchor` 与 `layer_z` 是相对宿主的表现坐标。地面效果在角色后方；接触效果依附真实目标；卡牌效果位于实际卡节点上。它们不改变角色内部“胸背 → 辫子 → 近侧手臂”的遮挡顺序。
- `lightning_chain` 的两端是局部 `[30,128]` 到 `[224,128]`。按起点和终点旋转/沿长度伸缩，宽度保持原值；不拉伸角色，也不在特效层重选目标。
- 只在权威游戏事件确认后播放。`card_vfx_bindings.json` 中的事件名是本包的可移植语义契约，**不是宣称已存在的 STS2 原生 API**。具体 Godot / C# 接入及验证状态见主包集成目录。
- 可移植表保留部分旧玩法语义：U15的净化、R29升级回收描述不适用于当前定稿。当前U15是消耗另一手牌后抽牌；R29是全手兽化、升级减费。以实际生产receipt与卡牌规则为准，不为迁就旧美术描述新增净化／回收效果。
- `card_animation_bindings.json` 决定角色动作；本库决定其外部、接触、卡面和状态效果。动画中的命中帧用于表现同步，不能再发起一次伤害结算。
- 音效逻辑名采用 `sfx.<effect_id>`，由主包 `audio/manifest.json` 解析。状态循环不在每次循环重新播放音效；群攻与多段音效可合并或限频，规则结算次数不能受此影响。

## 不能漏掉的时序

领域按实际普通攻击段附雷，群体雷伤只计一次完整逻辑雷伤。抽到状态/诅咒时先净化、再消耗、再补抽。领域延长只更新持续时间，不每次重放完整展开。压制只针对已识别、实际可压制的来源；未知来源保持游戏原行为。

迎战使用实际开始的敌人行动，保留该行动原来的目标。吸收归迎战发起者；对其他玩家的攻击不能冒出自己的吸收。X 牌与随机多段攻击完全读取权威段数和目标；支付 X=0 时不伪造命中特效。

兽化选择 0 张、取消选择、非法目标或手牌进入失败时，不播放“成功转换”。批量兽化先取牌再固定集合，转换后抽到的新牌不自动加入当次批次。已有形态保持原状态。升级、减费与保留沿用原卡实体；视觉不重新创建牌或回写费用。

重演不会新增出牌次数或雷电成长。汲取以实际生命损失和实际治疗为准，完全格挡时没有治疗回流。死亡、战斗结束、目标节点销毁会清理对应的持续视觉、音频和等待表现；复活不自动恢复已经结束的领域。

## 重建

在动画仓库根目录运行：

```bash
python3 vfx/scripts/build_vfx.py
python3 vfx/scripts/build_icons.py
python3 vfx/scripts/build_bindings.py
python3 vfx/scripts/build_examples.py
python3 vfx/scripts/validate_vfx.py
```

依赖仅 Pillow 与 NumPy，已经包含在主仓库依赖中。必要原始输入保存在 `source/`：原卡表、动作映射、批准角色图，以及上下文例图所需 B01 / T01 原画。均有来源与 SHA，本目录的重建不依赖其他仓库。独立校验使用音效 cue 接口快照；实际音频文件在动画包的 `audio/` 中。字体子集生成脚本记录官方 Noto 来源与 OFL 许可。

`reports/technical_validation.json` 只证明其列出的像素和引用检查。实际看过的素材及对应 SHA 单独记录在视觉审查里，技术检查不会自动把美术判断写成通过。
