# 独立角色图集

这套图集用于角色与战斗特效分开播放的接入方式。`manifest.json` 的全部图片和 JSON 路径均相对本目录；`atlases/` 中每段一个 RGBA PNG 图集及一个坐标 JSON。

共有 26 个动作序列，940 个运行帧，512×512，24 fps，每行 8 格。角色统一朝右，画布脚底锚点 `[250,442]`。帧矩形位于每段 JSON 的 `frames[].rect`，每帧时长位于 `duration_ms`。同时保留原工程的动作事件、姿态标记和骨骼位置。

所有图集是中性的原角色颜色，不含闪电、光圈、领域描边、领域染色等演出层。`skin` 字段提示动作所属状态，并不表示图集已经含有领域染色；领域效果由单独的特效或着色器负责。这样可以避免新特效与旧烘焙特效重复叠加。

这些帧从与本轮结构审查相同的冻结动画源直接渲染，完整 RGBA 都保留在 PNG 图集中。没有从 GIF 回采或从有损预览恢复，也没有另外重复保存 940 张 PNG。`validate_clean_atlases_v5.py` 将每个图集格的完整 RGBA 哈希与无特效审查的原始帧哈希逐项比对。

原 `animations/frames/` 与 `animations/atlases/` 仍是带既有演出效果的成品，可用于直接预览和旧接入。新接入若使用本目录，就不应再同时绘制旧整角色情景图集。
