## V5资产历史与V7卡片更新

独立 VFX、机制图标、无内嵌 VFX 的人物图集、CC0/原创声音、角色界面、组合视频、Godot 素材工程、实际导出的运行资源 PCK，以及基于已核实 API 的接入源。上述为V5资产历史；V7卡片更新为28张固定原图与61张实际重绘。人物动画及声音以独立动画包的最新清单为准，本卡片包中的历史数量不覆盖该包后续修订。

## 已导出的资源包

动画包的 `exports/VolibearArt_v5.pck` 为 **126933504 B**，使用 `res://VolibearArt/` 命名空间，包含 26 组 clean 角色图集（940 帧）、40 组 VFX 图集（1070 帧）、47 个独立 OGG（54 个 cue）、14 张 UI PNG、16 套机制图标（64 张 PNG 与16份 SVG），以及相关 JSON 和89卡表现绑定。完整编辑源、WAV 母版、卡牌插画及研究参考仍在各自的 repo 目录中。

此 PCK 已用 Godot 4.5.1 在独立空工程中挂载，检查实际纹理、音频和 JSON；报告为动画包 `exports/VolibearArt_v5.report.json`。它是可用的资源包，不是已注册、已编译或已通过 STS2 实机测试的 Mod。游戏角色/卡牌模型、DLL、Mod manifest 和目标版本接入仍由实际游戏工程完成。入口与重建说明见动画包 `exports/README.md`。

## 使用范围与验证范围不同

素材已完成不等于游戏玩法已实现。Godot 自检可以证明实际图集被引擎读取、构建帧和清理实例；不能证明 STS2 中战斗结算、卡组存档、多人同步或目标 DLL ABI 正确。来源许可同样按各素材记录处理；音频 CC0 不表示角色 IP 也变为 CC0。

完整交付证据在动画包的 `reports/DELIVERY_V5.md` 与 `integration_sts2_v5/docs/UI_PROFILE_MAP.md`；研究报告 `STS2_SUPPORT_V5.md` 同时放入三个包各自的资料目录。
