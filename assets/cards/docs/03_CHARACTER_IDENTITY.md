# 已定角色与抽象化办法

## 权威参考

`references/identity/volibear_approved.png` 是用户上传的已定稿造型。它负责回答“这是谁”；`state/style_lock.json` 中的已认可项目图，以及独立参考仓库精选的原作卡图负责回答“怎样把它画成卡牌插画”。不把造型图原有的渐变、毛发细节密度和站姿直接复制到所有卡牌。

## 必须保留的设计关系

1. 厚重的熊形，宽肩、粗臂、短而宽的口鼻、圆耳。不是精瘦人类身体套熊头。
2. 头、颈、肩部是暖白/灰白毛面；前臂、下身与阴影偏深蓝灰。
3. 青蓝眼、青蓝爪、肩臂的角状蓝色纹路构成同一套能量语汇。
4. 胸前两条白色辫束、旧铜箍与青蓝几何符坠。画面看得到完整胸口时保留；爪部特写不需要硬塞进去。
5. 背后深蓝色尖簇形成有重量的背部轮廓；它们是背部特征，不移成头顶双角。
6. 鼻口为深色，表情有力量和凶性，避免宠物卖萌脸、柔圆玩偶比例和大眼吉祥物化。

## 按镜头简化

| 镜头 | 留下 | 可以省略 |
|---|---|---|
| 头部/咬击 | 熊鼻、口鼻宽度、圆耳、青眼、咬合关系 | 胸辫、腿、完整背峰 |
| 单爪 | 粗前臂、深蓝毛面、青爪、白毛分界或蓝纹 | 头、另一臂、环境全景 |
| 胸肩防御 | 前臂护住要害的结构、肩的重量、白毛深影、适量辫饰 | 完整脚掌、每片毛簇 |
| 脊背 | 背峰节奏、白肩与深蓝背的分区 | 正脸与胸坠 |
| 全身概括 | 宽肩低头、熊耳/宽吻外缘、粗臂、脚下重心 | 精细毛发、所有铜箍纹样 |
| 能量熊形 | 仍是同一宽肩熊的主轮廓，再用白/蓝色块、负形或青色轮廓组织 | 写实材质、完整五官 |

## 指定动作

### B01 打击

角色解剖学右臂位于画面左侧，向画面右下方挥爪。镜头抓挥击已经进入下行阶段的瞬间，裁取右臂、肩部与少量躯干。右肩前送、躯干随之扭转，肘腕与爪尖形成连续动作。不能只把爪子贴在静止立绘上，不能翻成画面右侧的左臂出击。

### B02 防御 · V3

近侧臂自然横护胸，远侧臂竖起护面，两条肩—肘—腕链条彼此独立。躯干缩紧，肩膀迎向冲击；以局部特写强调厚重和受力。不能让前臂从另一肩穿出、围绕头胸成为闭环，也不能直接镜像打击图。

### U28 雷霆反扑 · V3

一条完整前臂屈肘迎击，另一拳收在肋部。金色来击抵达外侧前臂，青色返雷从接触处向外弹开。两掌都要保留结构，不能画成由光效覆盖的圆筒炮口。

### R28 熊灵侵染 · V3

施术者保持完整：一只自然的熊前臂和爪掌按住外部石板。接触附近局部转成深蓝粗粝皮毛纹与青色角纹，其他石面维持原材质。用接触和材质扩展说明侵染，不让熊自己变形，不用熊头贴片或头颅融合。

## 同一角色的三个视觉版本

具体熊、剪影熊、能量熊之间保持相同的肩宽关系、耳/吻轮廓与背峰节奏。抽象化是保留关系并合并细节，不是每次重新设计一只熊。选择参考图时，明确标注每张参考的职责；严禁从原作角色复制面罩、机械手、星冠或骨手作为沃利贝尔的装备。

## 变体与升级

89张独立卡共享这套身份。基础与升级共用同一张原画，只改游戏文字与数据。日后如果牌名、数值变化但主要动作不变，继续复用原画；主体、动作或身份变化时才重新排入绘制队列。
