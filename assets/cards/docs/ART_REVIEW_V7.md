# V7 美术与结构审稿标准

## 已执行范围

本轮28张用户固定图保留，61张实际重绘并逐张审稿，包含U28。原图、固定基准、250/125缩图、125灰度与STS1两种遮罩均纳入最终根审。生成者之外的跨组审稿覆盖61张，具体发现与修正按图像SHA记录。

风格采用少数连续硬边大色块、厚重剪影、明确冷暖对比和克制亮色。白灰肩毛、深蓝体块、短厚熊吻、青眼/青爪是实体角色可用身份线索；未出现在镜头中的部位无需硬塞。M0明确实体，M1以整体剪影概括，M2允许纯环境、器物与轨迹承担动作。

## 用户指出的“怪异”转成可检查问题

| 问题 | 实际检查方法 | 退回条件 |
|---|---|---|
| 扭曲肢体 | 从肩到爪逐段追踪；检查肘腕弯向和连接 | 多关节、断腰、悬空掌、截掉腿后用阴影掩盖 |
| 反向爪面 | 先分掌面/掌背，再看指端、爪根和收尖 | 掌面向内而爪从外侧指节生出；爪长在腕侧 |
| 混乱遮挡 | 给前后对象确定连续轮廓与层次 | 遮挡顺序前后跳变、辫子穿臂、轮廓无理由中断 |
| 动作没有逻辑 | 明确施力者、接点、受体和结果 | 特效没有源点、侵染只改变自己、转换位置与接触/影界无关 |
| 可笑的风暴形态 | 用整体大形、尺度和留白表达重量 | 圆团躯体、软胶般弯折、乱伸肢体、把剪影做成杂零件 |
| 爪子重复 | 对照整组镜头、动作轴、对象与负形 | 只换背景或爪色，仍是同一个左到右长臂构图 |
| 缩小后乱 | 原尺寸125×95彩色及灰度直接看 | 主动作丢失、亮效吞轮廓、背景碎纹比主体抢眼 |
| 器物像断肢 | 检查外壳/铆孔/刃面是否连续 | 独立指根、活体腕根、莫名关节或漂浮指甲 |

抽象可以减少体块和细节，但不能改变实体结构需要遵守的因果。完整角色只需画出该机位真正可见的肢体，不能为“凑齐四肢”额外加肢。

## 基准分组与取舍

28张固定原图是用户已认可的参考集合。每张重绘对照两张相关固定图，按主形清晰、动作关系、气质和完成度比较，不复制具体构图。`data/v7/benchmark_groups.json` 保留分组；逐卡实际基准在 `reviews/<ID>.json` 和对照板中。

本轮将画面扩展为承力接触、完整身体动作、环境路径、整体云影、器物与局部材质变化。主焦点在头盔、石路、外部护片或地面边界时，角色可以只出现自然裁切的局部，或完全不出现。

U28使用后侧俯视、可见敌人和分向回雷；固定U35仍为侧面举臂及地面波。二者在机位、角色占位、能量路径、色底和受体数量上区分，实际对照在 `previews/v7/U28_U35_comparison.jpg`。

## 独立评分

每张先通过9项硬门槛，再按五轴各20分排序：主读、大形、气质、完成度、差异。总分是审稿者对这套完成图的主观比较；28张固定图不重新评分。详细61行排名、各轴和实际观察均在 `reports/revision_v7/quality_ranking.json`，图库可从低分开始检查。

返修不是填写表格：例如C04撤回初次通过后改掉长斜臂；U31压简碎岩；U41将像断掌的内层改成一体刃板；R27经过实际编辑使两件器物共同跨过熊影边界。旧版拒绝记录保留，最终批准仅对最终SHA有效。

跨审中的非阻断语义意见也保留。U05读作双掌协同借支点翻顶巨岩；R25用旧边界槽的断面重连隐喻领域恢复。它们有明确动作，但卡名与规则仍参与机制理解；不声称插画单独能唯一传达所有玩法。详见 `reviews/v7/root_cross_review_responses.json`。

## 文件验证与视觉判断的分工

PNG完整解码、尺寸、重复字节/像素、母图裁切、遮罩、文件路径和SHA由脚本验证；关节、受力、情绪和视觉重复由实际看图的人类式判断完成。独立图像审查不等于保证每个人的审美一致，技术检查也不等于游戏内集成验证。
