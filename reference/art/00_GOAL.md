# 参考资料使用目标

此仓库只保存必要参考，无需再次下载全量卡图。

1. 先读 README.md、research/V5_SHOULDER_AND_OCCLUSION.md，再参考research/08_SOURCE_PRESERVATION_V4.md的原图保全历史。
2. 做角色动画时以 identity/ 原图为体型基准，用 motion_examples/ 判断动作重量与节奏，不能照着研究视频替换角色身份。
3. 做卡面时用 project_examples/B01、U19、U37 校准直观构图及结构，再按图形需要挑少数 style_examples；不把任何旧失败图作为正向锚点。
4. 在动画或卡片成品仓库中执行对应 00_GOAL.md，把实际新资产、独立审查和导出落到所属仓库。
5. 不以参考研究代替真实图片检查，不把参考资料复制为运行时游戏素材。

6. 每次重新切块后，先以统一坐标逐部位对照原图，确认躯干、髋和双腿没有被误删，再检查全部受影响动作。爪子要核对掌面、掌背、指节与指甲的共同朝向。

## V5检查重点

先看research/V5_SHOULDER_AND_OCCLUSION.md：前臂在辫子之前，关节内缘随臂运动且由身体遮挡。原图保全是必要条件，不代表所有原像素放到任何动画层都正确。研究采用固定框架提交，新增支持结论要回到作者源码/官方文档核实，分清框架扩展、项目约定与游戏硬要求。保持三个完整包及TR范围说明；引用声音来源时核对真实文件和许可，不能用下载失败页面声称已拿到官方配音。
