# 沃利贝尔卡牌插画风格规范

本规范把《杀戮尖塔 2》的实图观察转化为本项目的生产要求。它不是 Mega Crit 的内部美术手册。研究依据见 `01_RESEARCH.md`；角色身份以 `identity/volibear_approved.png` 为准。

## 一句话目标

用**明确的轮廓、概括的体块、少量硬边明暗和有方向的效果形状**，画出有重量、有野性、易于在小卡面辨认的沃利贝尔；一张图只建立一个主要视觉动词。

英文风格描述：**graphic stylized fantasy card illustration, expressive silhouette, selective bold contours, angular cel-shaded color masses, economical detail, readable at thumbnail size**。

这不是“每张都画一只白熊站在蓝色闪电里”。角色统一来自形状、配色关系、材质画法与身份特征；单卡差异来自动作、视点、主形、负形与亮暗组织。

## 1. 轮廓与体块

- 第一层读主体：拳爪、肩背、熊形、落雷、足印或被压制的形状。
- 第二层读动作：挥下、顶住、咬合、汇入、迸出、环绕、压下。
- 第三层才读纹样、毛簇、铜箍与碎片。
- 身体用胸肩、上臂、前臂、腹部等大体块交代；毛发收束成几组楔形毛簇。
- 主体外缘可以有深色描边，也可以靠明暗色块相接。不能把每条内部边都描成同样粗细。
- 动作靠重心、肩线、躯干扭转和遮挡关系成立；运动线负责增强，不代替身体动作。
- 掠过边缘的主形可以出画。关键接触点、主要爪尖和角色辨识点留在安全范围内。

## 2. 色块、明暗与效果

主体通常用底色、阴影、亮面三个层次组织；有需要时再增加一个强调层。这是项目的简化原则，不是对原作颜色数目的统计。

主要体积转折采用硬边。允许背景低频渐变、局部光晕、能量透明叠色；这些效果不能让主体轮廓糊成雾。禁止以毛丝、噪点、体积烟雾和密集粒子填满画面。

雷电先画**连贯的大分支**，再加少量分叉。白芯、青蓝边、深蓝遮挡应形成清晰层次。雷可以成为主角，也可以只在一个接触点出现；普通肉搏牌不强制附加雷电。

建议色彩角色如下，色值用于校准，不要求逐像素匹配：

| 色彩角色 | 建议色值 | 使用方式 |
|---|---|---|
| 暖白毛面 | `#DDD8CA` | 头、颈、肩等大亮面 |
| 冷灰毛影 | `#969CA8` | 连接亮面与深蓝身体 |
| 深蓝身体 | `#344158` | 前臂、腿、身体暗部 |
| 最深轮廓 | `#141D2D` | 关键外缘、口鼻、背部主峰 |
| 青蓝身份色 | `#5BCFF3` | 眼、爪、少量符纹 |
| 雷电亮芯 | `#ECFCFF` | 效果焦点；控制面积 |
| 旧铜 | `#8D7656` | 辫箍与饰件，小面积 |
| 暖对比色 | `#BB6B3E` / `#D8AF70` | 背景、敌方攻击、岩块；不用来改角色毛色 |

### 背景不固定成蓝色

允许深紫、砖红、赭石、灰绿、暗青和冷灰背景。白毛遇浅背景时，以深蓝轮廓、前后明度差或大阴影拉开。雷电牌可以用暖暗背景突出青白雷，防御牌也可以是暖色。颜色帮助记忆卡牌，不承担卡牌类型或稀有度的唯一编码。

## 3. 三个抽象等级

| 等级 | 画法 | 身份保留 | 合适用途 |
|---|---|---|---|
| M0 具象概括 | 可见熊的头胸、肢体结构，细节仍经过删减 | 该镜头内可见的配色分区、口鼻耳形、符纹、辫饰与背峰 | 基础动作、咬击、格挡、姿态 |
| M1 剪影概括 | 肢体合并成更大的形，局部以轮廓或发光线识别 | 至少两种可见身份特征；不能只靠“蓝色雷” | 躯体状态、受击反扑、神力、持续能力 |
| M2 图形符号 | 用爪痕、熊形负形、符纹、足印、雷脉等表达 | 局部专属结构或与系列一致的组合语汇；不强塞完整头像 | 雷法、蓄势、检索、本能、回路 |

M2 不是无条件简笔画。它可以有体积，也可以有局部描边；它的目标是减少叙事对象，使效果本身成为可读的主形。

### 身份最低条件

- 画头：保留宽厚口鼻、圆耳与白灰头部；不要画成长吻狼、角兽、狮鬃。
- 画爪：保留粗厚深蓝前臂、青蓝弯爪以及白毛分界或角状蓝纹中的一项。
- 画全身剪影：保留宽肩低头、熊耳/口鼻的外形，以及背峰或白上深下的关系。
- 画纯效果：可在负形、断面或线条节奏中放入熊耳双峰、三道爪势、角状符纹等；蓝色闪电本身不算沃利贝尔专属标记。
- 有些原作卡仅画通用符号。为本项目量产一致性，我们在纯符号牌里增加系列形状语汇；这是本项目约定，不假称原作每张都能独立认出角色。

## 4. 构图配方

每张牌从下面取一个主配方，再按逐卡简案修改。不能机械套用同一模板。

| 配方 | 主结构 | 适用例 |
|---|---|---|
| 局部斜切 | 一只爪或前臂从边缘进入，动作沿一条斜线 | 打击、磨砺爪牙 |
| 压缩与顶住 | 外部攻击挤入，主体形成稳定楔形或弧形 | 防御、正面迎敌 |
| 重复节奏 | 两到三条具有错位的主形 | 双爪、三重撕裂、裂天 |
| 质量对撞 | 两个体块相接，接触点是唯一最亮处 | 挟山、崩山 |
| 容器与流向 | 雷/气/力量被吸入、沉积或导出 | 接地、雷涌、力量归身 |
| 稳定中轴 | 低重心、宽肩、纵向支撑或闭合体块 | 屹立、不动神躯 |
| 展开/环抱 | 角色或领域包围局部，外部形状被压下 | 显圣、风暴形态 |
| 负形显现 | 环境或效果之间留出熊形、爪形 | 我即荒野及纯符号效果 |
| 接触与局部侵染 | 完整爪掌触碰外部对象，接触处改变材质 | 熊灵侵染 |
| 道具/痕迹 | 只画痕迹、符坠、足印、局部皮毛 | 战痕、追猎准备 |

不要让所有能力牌都采用居中正面全身像。不要让所有雷法都采用中央球体加四周放射线。不要让所有防御牌都套同一个透明圆盾。

## 5. 与机制的连接

美术表达主要动作或情绪，不把整段规则翻译成流程图。抽牌不必画扑克牌；能量不必画数字；升级不必加更多闪电。优先找卡名、机制和角色动作的交集。

- **迎战**：主体主动接受冲击；不同卡分别强调挑衅、贴近、顶住、受压反弹、环向迎敌。
- **领域**：空间秩序被熊的形状控制；外部细碎法术在边界上断开或沉降，强调压制。
- **雷电成长**：主分支增粗、流向汇合或体内纹路贯通；不使用统计数字。
- **兽化**：外部对象或抽象手牌载体发生局部爪/躯形变化。熊灵侵染必须看出完整熊爪接触外物、接触处局部改变；施术者保持自身完整，不用熊头贴到物体或熊体融化替代侵染动作。
- **格挡**：重量、皮毛、身体支撑、硬边能量面；避免一律拿盾。

规则表原文另存。领域视觉按用户明确的“攻击、格挡、力量保留，其他敌方特殊机制禁用”口径设计。不能用插画设计为旧表中的例外背书。

## 6. 图像规格与安全区

- 单幅横向插画；完整画布比例 **25:19**。
- 首选生成母图 **2000×1520**，最低交付母图 **1000×760**。工具返回其他尺寸时保留原图，显式裁切，复审后再导出。
- 不画卡框、卡名、费用、说明文字、稀有度宝石、水印或排版。
- 普通插画母图为不透明 RGB/RGBA；透明角色立绘仅作身份参考。
- 中央约 80% 宽、80% 高是默认重要信息区。边缘可以裁掉毛簇、环境和延伸雷电；不可裁掉完成动作所需的手腕连接、口鼻关系或受力接触点。
- 一代卡型遮罩另有预览；安全区比例只是初筛，实际遮罩预览与小图检查才决定通过。

## 7. V3 风格锚点与结构门槛

用户认可的 B01、U19、U37 作为正向例保留。旧 B02、U28、R28 已在本轮否决并重做，不能继续作为新图的结构参考。V3 成品仓库中这几张的新修正版可用于自然格挡、反击与接触侵染的动作参考。

风格统一来自少量硬边明暗、大色块、角色身份和可读主动作。新图必须单独通过 `07_ANATOMY_AND_ACTION_V3.md` 的八项门槛；旧分数不用于豁免结构错误。维护时只修受影响卡，不从整套先导图重新生成。
