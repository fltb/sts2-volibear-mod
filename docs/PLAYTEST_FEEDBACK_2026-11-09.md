## B. 攻击牌多段化（力量协同）

共识：力量源很多，但吃力量的攻击牌太少；白攻击普遍弱，前期输出像猎人。方向：把白攻击改多段，让力量收益自洽。

| 卡 | 现状 | 建议 |
| --- | --- | --- |
| C22 雷震 | 2c，全体 (5 伤害 + 2 雷伤) ×2，升级 +2 伤害 / +1 雷伤 | **升级改成 3 段**，基础数值调低（如 4/2 ×2 → 敲后 3 段） |
| C08 撕开伤口 | 1c，8 伤害 + 1 易伤，升级 +2 伤害 / 易伤 +1 | **基础 4 伤害 + 1 易伤；升级变 2 段**（每段 4，与领域联动） |
| C04 擂首一击 | 1c，9 伤害 + 1 虚弱 + 迎战 | 虚弱 **2/3**（基础 2，升级 3） |
| C01 逼近 / C05 雷霆爪击 / C06 进逼 / C07 追嗅 / C20 乘势追击 | 单击 | 建议改多段（见正文选择） |

多段注意事项：每段都吃力量 → 改多段是隐性加强，总伤建议保持或略降；攻击段数本身不算"雷伤"。
