## 更新规则

1. 完成一项即更新对应勾选；尚未完成的项不能因编译成功或文件存在而勾选。
2. 实现遗漏与正确性失败分开记录；不以未测试冒充缺实现，也不以已实现冒充测试通过。
3. 若发现新的明确遗漏，追加具体功能和位置，不使用“继续研究／全覆盖”之类无边界条目。
4. 不提交游戏程序集、反编译资料、本机配置、存档、临时测试产物或秘密。
